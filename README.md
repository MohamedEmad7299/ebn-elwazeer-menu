## ✨ المميزات الرئيسية (Key Features)

1. **نظام ثنائي اللغة فائق السلاسة (Bilingual Support - AR / EN)**:
   - التبديل الفوري بنقرة واحدة بين العربية (RTL) والإنجليزية (LTR).
   - حفظ تلقائي للغة المفضلة للزائر في المتصفح عبر `localStorage`.

2. **قائمة طعام شاملة وتفاعلية (Interactive Menu & Categories)**:
   - شريط تصنيفات انسيابي ثابت (Sticky Tabs) لسهولة التصفح السريع.
   - بحث فوري حي (Live Instant Search) يبحث في أسماء ومكونات الوجبات باللغتين.
   - تبديل أحجام الوجبات والبيتزا والزلابية (S / M / L) وتحديث الأسعار لحظياً في البطاقة.
   - وسوم مميزة للأصناف (الأكثر طلباً ⭐، سبايسي 🌶️، مميز 👑، مشوي 🔥، مقرمش 🍗).

3. **سلة طلبات عائمة وشريط ذكي (Floating Cart & Drawer - Talabat/Elmenus Style)**:
   - شريط عائم سفلي أنيق يظهر تلقائياً مع أول صنف مضاف.
   - درج سلة كامل يتيح زيادة وإنقاص الكميات (+ / -) وحذف الأصناف.
   - حقول إدخال اسم العميل ورقم الموبايل والملاحظات الإضافية.

4. **نافذة اختيار خط الطلب والتوصيل (Branch & Dispatch Picker)**:
   - نافذة منبثقة بنظام Bottom-Sheet على الهواتف مع أزرار راديو جانبية وبحث سريع.
   - توجيه الطلب تلقائياً ومباشرة إلى رقم واتساب الفرع أو الخط المختار.

5. **تنسيق وإرسال الطلب عبر واتساب (WhatsApp Order Dispatch)**:
   - تجهيز رسالة واتساب منظمة ومفصلة بأسماء الأصناف، خيارات الحجم، الكميات، الإجمالي، والملاحظات بضغطة زر.

6. **مولد رمز الاستجابة السريعة (Dynamic Table QR Code)**:
   - رمز QR عالي الدقة يفتح المنيو فوراً عند مسحه بكاميرا أي هاتف ذكي.
   - زر مدمج لتحميل صورة الـ QR بدقة فائقة لطباعته على ستيكرات الطاولات والمنشورات.
   - زر نسخ رابط المنيو بضغطة واحدة.

7. **عارض المنشور والبروشور الأصلي (Original Printed Flyer Lightbox)**:
   - إمكانية استعراض النسخة الورقية المطبوعة بدقة عالية عبر نافذة منبثقة تفاعلية مع تبديل الصفحات.

## 🚀 النشر على GitHub Pages (Deployment Steps)

1. أنشئ مستودعاً جديداً على GitHub باسم `ebn-elwazeer-menu`.
2. ارفع محتويات المجلد إلى الفرع الرئيسي `main`.
3. انتقل إلى **Settings** > **Pages** داخل المستودع.
4. تحت **Branch**، اختر `main` واضغط **Save**.
5. سيصبح الموقع متاحاً على:
   `https://mohamedemad7299.github.io/ebn-elwazeer-menu/`
